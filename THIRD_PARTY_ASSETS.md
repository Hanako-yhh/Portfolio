# Third-party assets

The Noventure prototype includes the following user-approved visual sources. Files are stored locally so the experience does not depend on third-party requests at runtime.

## Solar System Scope textures

- Source: https://www.solarsystemscope.com/textures/
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Credit: Solar System Scope
- Included files: `sun.jpg`, `mars.jpg`, `earth-day.jpg`, `earth-clouds.jpg`, `jupiter.jpg`, `venus-atmosphere.jpg`, `neptune-solar-system-scope.jpg`
- Use in Noventure: surfaces for Noventure A, Cinder, Haven, Aurelia and Pelagos; Haven also uses the cloud layer.
- Modifications: textures are lit, tone-mapped and combined with animated real-time climate layers. Planet identities and scale are fictional.

## NASA Deep Star Maps 2020

- Source: https://svs.gsfc.nasa.gov/4851/
- Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio; Gaia DR2: ESA/Gaia/DPAC
- Included file: `deep-star-map-2020.jpg` (web-resolution print map)
- Use in Noventure: distant all-sky background, colour-graded and combined with a procedural foreground star layer.

## ESO LDN 483

- Source: https://www.eso.org/public/images/eso1501a/
- License: Creative Commons Attribution 4.0 International (CC BY 4.0), subject to ESO image usage terms
- Credit: ESO
- Included file: `ldn-483.jpg` (screensize JPEG)
- Use in Noventure: faint background structure with reduced opacity, edge masking and colour grading.

## Interface libraries

- Lucide icons — ISC License; used through the `lucide-react` package.
- Noto Sans SC and Orbitron remain the intended typefaces; the current build uses local/system fallbacks until font files are bundled.

## Software icons

- Figma icon — downloaded from Figma's official brand asset package and used unmodified to identify the Figma platform: https://www.figma.com/using-the-figma-brand/
- Codex icon — downloaded from the official OpenAI Codex product page image asset and used to identify Codex: https://openai.com/codex/
- MasterGo icon — converted from the official `mastergo.com` favicon to PNG without altering its proportions: https://mastergo.com/favicon.ico
